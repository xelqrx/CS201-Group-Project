## ---Іменники та дієслова----

дієслова:
стояти - велосипед<br>
бути звичайним/електричним - велосипед <br>
мати - клієнт <br>
взяти - клієнт <br>
покататись - клієнт та велосипед <br>
повернути - велосипед <br>
коштувати - велосипед <br>
списуються - клієнт <br>
стоїть - велосипед <br>
заробила загалом - адмінстратрр <br>


методи
- перевірка чи є на станції велосипед
- здійснення поїздки(поєднання 2 методів переставити велосипед і зняти гроші з балансу, за умови що велосипед є)
- показати баланс
- сформувати звіт(зароблено грошей і кількість велосипедів на станції)

## ---Картки класів----

| Клас | Що він знає(атрибути) | Що він вміє(методи) |
| ---- | ---- | ---- |
| Клієнт | ID, Імʼя ,баланс, Активований велосипед(при користуванні) | Змінювати баланс, показувати баланс, (assign велосипед),  перевірка на борг |
| Велосипед | свій вид (електрика/норм), номер, чи взятий якимсь клієнтом | поїздку |
| Станція | велосипеди які тут є, свій номер/назву | глянути наявність велосипедів |
| (Адміністратор) | загльний баланс, ID | глянути звіт |
